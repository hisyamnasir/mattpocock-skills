The repo now installs as a Devin plugin: `devin plugins install mattpocock/skills`, or **Customize → Plugins → Add plugin → From repository** in the web app. `.devin-plugin/plugin.json` ships the promoted skills from `skills/engineering` and `skills/productivity`, and `scripts/sync-plugin-version.mjs` keeps its version in step with `package.json`.
